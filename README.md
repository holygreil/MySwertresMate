# 🎯 My SwertresMate

### PCSO 3D Lotto Statistics & Analysis

**My SwertresMate** is an Android application designed to help users explore historical 3D Lotto results through statistical analysis, frequency patterns, and number-combination tools.

It is intended as an **analysis and reference tool**, not as a guaranteed-number generator.

## 📊 What My SwertresMate Does

My SwertresMate analyzes available historical results and presents statistical information such as:

* Digit frequency
* Position frequency
* Recent results
* Hot, warm and cold digits
* Combination frequency
* Statistical candidate rankings
* Statistical Grid analysis

The application uses these calculations to organize historical data and generate statistical candidates for analysis.
